## Preservação de jogos

Alguns dos meus jogos de celular favoritos saíram das lojas e não rodam mais nos aparelhos atuais, então eu os reconstruo a partir do que sobrou. A regra que eu sigo: transcrever a lógica original, não refazê-la no olho. São projetos pessoais e privados de preservação.

**Heavy MACH: Defense** (iOS, 2011) · porte para Unity, no Android e no Windows
- Lógica do jogo transcrita do binário original, pela decompilação no Ghidra e pelo assembly ARM.
- As 80 fases, as 110 unidades e a interface completa.

**Heavy MACH: Assault** (iOS, 2011) · porte para Unity, no Android
- Feito sobre o mesmo motor interno do Defense, então os dois portes compartilham o código do motor. Cada classe de jogo, porém, foi transcrita do binário do Assault: o mesmo nome de classe não significa a mesma lógica.
- 43 mapas, 720 definições de mech, 8 missões e o modo Survival. O controle por inclinação usa a fórmula exata do acelerômetro do original.

**Retry** (Rovio, 2014) · reconstrução em Unity 6 para celulares Android só de 64 bits, onde o APK original não roda de jeito nenhum
- Shaders reescritos a partir do dump em ShaderLab de 2014.
- 177 sprites perdidos recuperados do APK original.

## Ferramentas e apps

| Projeto | O que faz | Tecnologias |
|---|---|---|
| **Net Doc** | Monitoramento contínuo de rede no Windows. Diz onde a rede quebrou e por quê, em linguagem clara. | Python, PyQt6, SQLite |
| **VEIL** | App de chat local feito a partir de uma especificação escrita. Roda com LLMs locais, com uma memória que guarda de onde veio cada fato. | TypeScript, React, Fastify |
| **Nexus** | Gestão escolar para professores: turmas, notas e boletins. | FastAPI, Flutter |
| **Typus Desktop** | Cliente de Windows para um app de chamadas, com seletor próprio de compartilhamento de tela e integração com a bandeja. | Electron |
| **Site imobiliário** | Anúncios de imóveis com painel administrativo e notificações por e-mail. | React, Vite, Node.js, Express |

A maioria dos meus repositórios é privada. Alguns projetos antigos de estudo são públicos, como o [MCDU](https://github.com/Nicky-H/MCDU) (Python orientado a objetos) e o [Pacetech](https://github.com/Nicky-H/Pacetech) (meu primeiro curso de algoritmos).
